Layout Architectures

Technical Comparison: 1-Dimensional CSS Flexbox vs. 2-Dimensional CSS Grid

1-Dimensional

CSS Flexbox

Approach: Content-First. Elements size themselves naturally while the container distributes and aligns them along a single axis.

  • Primary Role: Linear distribution (Row or Column).
  • Alignment Control: justify-content & align-items.
  • Best Fit: Navigation bars, action button clusters, badges, breadcrumbs, centered card contents.
  • Applied in Lab 2: Sticky header, brand identity, and nav links.
2-Dimensional

CSS Grid

Approach: Layout-First. The container defines a rigid coordinate structure of tracks, and items occupy precise slots.

  • Primary Role: Planar distribution (Rows and Columns simultaneously).
  • Template Syntax: grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)).
  • Best Fit: Multi-column portfolio cards, image galleries, complex app dashboards.
  • Applied in Lab 2: 6-card responsive project gallery.
